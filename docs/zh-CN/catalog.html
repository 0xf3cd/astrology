rule.house.whole_sign · 整宫制¶

排盘适配层显式选择 celestial-calendar 的 WHOLE_SIGN 几何，再按 rule.project.cusp_ownership 将黄经归入给定宫头所界定的宫。上升点不必与第一宫头重合。

rule.node_definition.mean · 平均月交点¶

适配层将 MEAN 交点定义对应到上游的平升交点和平降交点。方向由各 LunarNode 身份保留；此定义不选用五项修正。

项目定义绑定，不是精度档位。

项目测试按参考公式计算平交点，加上章动项，再与上游结果比较。这不表示已核验 Meeus 印刷原文或确立误差界，也不表示它可与真交点或密切轨道交点互换。

Concepts / 概念：node_definition.mean

Configuration request / 配置请求：astrology.config.NodeDefinition.MEAN = mean

rule.node_definition.meeus_five_term_true · Meeus 五项真月交点¶

适配层将 MEEUS_FIVE_TERM_TRUE 对应到上游的真升交点和真降交点。项目以平交点加五项正弦修正及章动项对照结果，据此认定级数；上游目标名称本身未指明该级数。

项目定义绑定，不是精度档位。

这是实现对拍，不是独立天文互证。Meeus 印刷原文、误差界及与密切轨道交点的等价性仍未核验。

Concepts / 概念：node_definition.meeus_five_term_true

Configuration request / 配置请求：astrology.config.NodeDefinition.MEEUS_FIVE_TERM_TRUE = meeus_five_term_true

rule.project.aspect_deviation · 相位偏差与分支¶

有向间距从第一个对象指向第二个，是黄经上取值在 (-180, 180] 度内的差。精确角度为 θ 的相位，在间距与某个分支的差不超过限度时成立，限度本身包含在内。六分、四分、三分相的分支是 −θ 和 +θ，合相与对分相只有 0 或 180 这一个角度。凡成立的分支都会报告，顺序是先按对象，再按相位角，同一相位里负分支在正分支之前。

项目约定，不归于某个传统。

仅限黄经。黄纬、赤纬、次要相位、整宫相位及与轴线的相位都不判断。

Concepts / 概念：aspect.conjunction, aspect.sextile, aspect.square, aspect.trine, aspect.opposition

rule.project.aspect_motion · 入相与离相状态¶

对同一时刻的位置和速率，相对黄经速率是第二个对象的速率减去第一个的速率。偏差不为 180 度时，相对速率与偏差异号表示入相，同号表示离相。偏差恰为零表示精确；相对速率恰为零且偏差不为零表示静止，意思是两个对象没有相对运动，不表示某颗行星的黄经速率为零。缺少速率时为不确定。偏差恰为 180 度且存在相对运动时，回绕后的绝对偏差没有双侧导数，状态为不确定。直接比较浮点数，不使用容差。

项目定义，不归于某个传统。

只描述当前时刻，不预测相位之后会不会变得精确；任一对象都可能在达到精确相位前改变运动方向。

Concepts / 概念：aspect.conjunction, aspect.sextile, aspect.square, aspect.trine, aspect.opposition

rule.project.aspect_participation · 参与相位的对象¶

在单盘判断中，相位在已请求的对象之间判断，或在其中选出的子集之间判断。两个月交点之间不构成相位：四个交点标识只是同一对交点的两种定义和两个方向。月交点可以与天体构成相位。轴线不是排盘请求里的对象，不参与。

项目约定，不归于某个传统。

单盘判断中不判月交点之间的相位，是项目约定。某个惯例若根本不为月交点画相位，就把它排除在所选子集之外。
