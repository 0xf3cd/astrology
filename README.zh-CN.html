celestial-astrology¶

English | 简体中文

开发中的 Python 西方占星排盘与知识库。天文计算由 celestial-calendar 提供；本仓记录占星规则、 出处和流派变体，并组织可复现的星盘结果。

开发包提供不可变的出生记录与现代时刻解析、 排盘请求配置、热带本命盘计算、 命盘记录与文本输出、独立知识目录、质量检查和双语 API 文档。 天文库只在请求排盘或重算时导入，导入本包或查询知识都不会初始化它。 运行检查见参与开发。

安装随天文依赖而定：celestial-calendar 0.8.0 只发布 Linux x86_64 与 aarch64、 macOS 14+ arm64、Windows amd64 的轮子，没有源码分发包。其他平台无法安装本包， 连知识浏览也不可用。

从源码安装¶

分发包名是 celestial-astrology，Python 导入名仍是 astrology。 当前源码准备版本 0.1.0，尚未发布到 PyPI；请勿安装 PyPI 上另一个无关的 astrology 项目。

请在上述支持的平台使用 Python 3.11–3.14。 若要安装文档对应的固定源码版本，使用文档首页标明提交号的快照安装命令。 若已下载或克隆所需源码，则在其根目录运行以下命令。安装需要联网下载构建依赖和精确钉版的运行依赖。

Linux/macOS（可把 python3.14 换成其他受支持的 Python 版本）：

python3.14 -m venv .venv
.venv/bin/python -m pip install .

Windows PowerShell：

py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install .

这些命令从源码安装，不表示候选包已可从包索引安装。 开发检查使用 uv sync --locked，详见参与开发指南。

第一张命盘¶

把下面的 Python 脚本保存为 first_chart.py；它不是交互式终端记录。 Linux/macOS 运行 .venv/bin/python first_chart.py，PowerShell 运行 .venv\Scripts\python.exe first_chart.py。 输入明确使用 UTC 偏移和合成坐标；本例不请求相位。

from datetime import date, time, timedelta
from astrology import (
  BirthRecord,
  Body,
  ChartConfig,
  FixedOffset,
  HouseSystem,
  Location,
  TimePrecision,
  natal_chart,
  prepare_natal_input,
)

record = BirthRecord(
  date(2000, 1, 1),
  time(12, 0),
  FixedOffset(timedelta(0)),
  Location(0, 0),
  TimePrecision.MINUTE,
  {"example": "synthetic"},
)
config = ChartConfig(HouseSystem.WHOLE_SIGN, (Body.SUN, Body.MOON), ())
chart = natal_chart(prepare_natal_input(record), config)
print(chart.provenance.astrology_version)
print(chart.resolved.utc.isoformat())
for placement in chart.placements:
  print(f"{placement.identity.value}: {placement.sign.value}")

输出：

0.1.0
2000-01-01T12:00:00+00:00
sun: capricorn
moon: scorpio

时间未知或缺少地点时会明确拒绝，不补正午或推测地点；请求的宫几何无定义时抛出 ChartDomainError，不改用另一宫制。 排盘指南说明支持范围， 记录指南说明存取、重算与双语文本表格。

第一次查询知识¶

把这份独立脚本保存为 first_knowledge.py，用同一个虚拟环境的 Python 运行。 它读取包内目录，不排盘，也不初始化原生天文库；安装仍受上述平台限制。

from astrology import load_catalog

catalog = load_catalog()
print(catalog.concept("body.sun").name.text("zh-CN"))
print(catalog.lookup("日轮")[0].identifier)

输出：

太阳
body.sun

可继续浏览完整知识目录或 公开 API。 文档共用搜索索引，结果可能包含两种语言；中文采用相邻双字切分，不做语义匹配或词典分词。

首版目标¶

已知出生时刻和地点，计算现代热带黄道、地心本命盘：

  • 保存出生原始记录，显式处理时区，保留最终时标与计算来源。

  • 计算太阳、月亮、八颗行星及明确选择的月交点。

  • 支持 Whole Sign（整宫制）、Equal（等宫制）、Placidus；请求的几何无定义时显式失败。

  • 计算星座、二维黄经落宫（只用黄经，不用对象黄纬）、五大相位，以及可配置容许度和局部入相／离相状态。

  • 输出不可变结构、文本表格与带版本的序列化，保留输入、配置、天文原值和模型身份。

位置、四轴、宫头、星座、落宫、相位、文本输出及带版本的记录已实现。 恢复保留存储值，不调用原生天文库；重算则显式检查版本和模型是否可用。

交付任务与验收见 v0.1.0 milestone。
