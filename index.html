Install this source snapshot / 安装这一源码快照

Use a Python 3.11–3.14 virtual environment on a supported platform. The English and Chinese READMEs explain environment setup and first use.

.venv/bin/python -m pip install "https://github.com/0xf3cd/astrology/archive/5be995dfb9e27ddb043c5f1c2609cf8f48609eb4.zip"

.venv\Scripts\python.exe -m pip install "https://github.com/0xf3cd/astrology/archive/5be995dfb9e27ddb043c5f1c2609cf8f48609eb4.zip"
